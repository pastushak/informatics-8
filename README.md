# Інформатика. 8 клас — уроки для самостійного навчання

Сайт-курс на GitHub Pages: усі 70 уроків інформатики для 8 класу (НУШ) за підручником
Тріщук І. В., Лазарець О. Ю. «Інформатика, 8 клас» (Навчальна книга – Богдан, 2025).

На сторінці кожного уроку:
- коротка теорія з прикладами;
- вправи й самоперевірка з миттєвою перевіркою та поясненнями;
- практична робота з покроковою інструкцією, критеріями оцінювання і порадами «Якщо щось не виходить»;
- домашнє завдання;
- чек-лист уроку (прогрес зберігається в браузері учня і показується на головній сторінці).

Уроки 12–17 відкриваються з окремих сайтів `lesson-12-13`, `lesson-14-15`, `lesson-16-17`.

## Структура

```
index.html          головна: розділи, пошук, прогрес
lessons/01.html …   сторінки уроків
assets/style.css    спільний стиль
assets/lesson.js    вправи, чек-лист, прогрес, тема
```
