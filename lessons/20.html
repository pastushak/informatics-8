Кольори задають назвою (red), HEX-кодом (#1E7A55), rgb(30, 122, 85). Підбирати зручно на coolors.co або через пошук «color picker».

Підключення шрифтів Google Fonts

  1. fonts.google.comоберіть шрифт з підтримкою кирилиці (фільтр Language → Cyrillic): Roboto, Montserrat, Rubik, Comfortaa
  2. Get font → Get embed codeскопіюйте теги
  3. Вставте в перед підключенням style.css
  4. Застосуйте в CSSfont-family: 'Montserrat', sans-serif;
<link href="https://fonts.googleapis.com/css2?family=Montserrat:wght@400;700&display=swap" rel="stylesheet">

Читаємо

Блокова модель: розміри, відступи, рамки

Кожен елемент — прямокутна «коробка» з чотирьох шарів:

.card {
    width: 300px;
    padding: 16px;              /* усередині */
    margin: 20px auto;          /* ззовні; auto — центрує блок */
    border: 1px solid #ccc;
    border-radius: 10px;        /* заокруглення */
    box-shadow: 0 4px 10px rgba(0,0,0,.1);   /* тінь */
}
ПорадаДодайте на початку CSS * { box-sizing: border-box; } — тоді padding і border не збільшуватимуть заданої ширини.

Стани елементів: :hover і :focus

button {
    background: #1E7A55;
    color: white;
    border: none;
    padding: 10px 20px;
    cursor: pointer;          /* курсор-«рука» */
}
button:hover {               /* курсор над кнопкою */
    background: #155c40;
}
input:focus {                /* поле, в якому курсор */
    border-color: #1E7A55;
    outline: none;
}

Робимо · Практична робота №13

Створення форми реєстрації користувача

Мета: створити форму реєстрації з різними типами полів і оформити її зовнішнім файлом CSS з підключеним шрифтом Google Fonts.

  1. Підготуйте файли

    Папка register: index.html і style.css. У head підключіть шрифт Google Fonts і <link rel="stylesheet" href="style.css">.

  2. Каркас форми
    <h2>Форма реєстрації</h2>
<form>
    <label for="firstName">Ім'я:</label>
    <input type="text" id="firstName" required>

    <label for="lastName">Прізвище:</label>
    <input type="text" id="lastName" required>
</form>
  3. Додайте поля
    • Електронна пошта type="email";
    • Пароль і підтвердження пароля type="password";
    • Вік type="number" min="1" max="100";
    • Стать — <select> з трьома <option>;
    • Прапорець «Я погоджуюсь з умовами використання» type="checkbox";
    • Кнопка <button type="submit">Зареєструватися</button>.
  4. Стилізуйте сторінку
    * { box-sizing: border-box; }
body {
    font-family: 'Montserrat', sans-serif;
    background: #f4f4f4;
    margin: 20px;
}
h2 { text-align: center; }
form {
    width: 500px;
    margin: 0 auto;
    background: white;
    padding: 24px;
    border-radius: 10px;
}
label { display: block; margin-bottom: 5px; }
input, select {
    width: 100%;
    padding: 8px;
    margin-bottom: 12px;
    border: 1px solid #ccc;
    border-radius: 5px;
}
  5. Оформіть кнопку і стани

    Кнопка: колір фону, білий текст, без рамки, padding, border-radius, cursor: pointer. Додайте button:hover (темніший колір) і input:focus (кольорова рамка).

  6. Свій стиль

    Змініть кольори на власну гармонійну палітру (2–3 кольори), додайте тінь формі box-shadow. Перевірте в режимі смартфона (F12 → Ctrl+Shift+M).

Здача роботи
  1. Заархівуйте папку

    ZIP з index.html і style.css або посилання на codepen.io.

  2. Здайте в Classroom

    Архів + скріншот форми в браузері → Здати.

Якщо щось не виходить
Стилі не застосовуються

Перевірте, що style.css лежить у тій самій папці, що й index.html, і назва в href збігається до літери.

Шрифт не змінився

Назва в font-family має точно збігатися з назвою на Google Fonts, у лапках, а рядок підключення має стояти в head.

label і поле в одному рядку

Додайте label { display: block; } або ширину поля 100%.
