Читаємо

Кнопка, що змінює колір вікна

from tkinter import *

def change_to_green():
    window.configure(bg="green")
    window.title("Зелений")

window = Tk()
window.title("Зміна кольору фону")
window.geometry("400x300")

Button(window, text="Зелений", command=change_to_green, width=12).pack(pady=10)

window.mainloop()

Робимо · Практична робота №22

Складання програм з використанням математичних функцій

Мета: створювати програми з графічним інтерфейсом, у яких кнопки виконують обчислення.

Заготовки до роботи

⬇ Файли ПР №22pr22.zipАрхів з .py-файлами. Розпакуйте і відкрийте в IDLE / Thonny / VS Code. Місця, де треба дописати код, позначені # TODO.
  1. Завдання 1. Зміна кольору фону

    Вікно 400×300 «Зміна кольору фону» з трьома кнопками: «Червоний» (фон red, заголовок «Червоний»), «Зелений», «Синій». Для кожної кнопки — своя функція. додатково Задайте кнопкам розмір, колір, шрифт.

  2. Завдання 2. Периметр і площа прямокутника

    Вікно 400×400 «Периметр і площа прямокутника»: дві мітки і два поля (довжина, ширина), три кнопки: Обчислити периметр, Обчислити площу, Обчислити діагональ (math.sqrt), і мітка для результату. Результат округліть до 2 знаків.

  3. Завдання 3. Коло

    Поле для радіуса, кнопки «Довжина кола» (2 * math.pi * r) і «Площа круга» (math.pi * r ** 2).

  4. Завдання 4. Час додатково

    Користувач вводить кількість секунд — програма виводить години, хвилини і секунди (// і %).

  5. Консольний варіант

    Якщо Tkinter недоступний — виконайте завдання 2–4 з input() і print(); завдання 1 опишіть кодом без запуску.

Здача роботи
  1. Зберіть код

    Файли .py + скріншоти вікон з результатами.

  2. Здайте в Classroom
