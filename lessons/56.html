Нові віджети

site_type = StringVar(value="Лендінг")          # змінна для групи перемикачів
Radiobutton(window, text="Лендінг", variable=site_type, value="Лендінг").pack()
Radiobutton(window, text="Магазин", variable=site_type, value="Магазин").pack()
print(site_type.get())                           # яке значення обрано

design = BooleanVar()                            # прапорець: True / False
Checkbutton(window, text="Дизайн", variable=design).pack()

days = Scale(window, from_=7, to=14, orient=HORIZONTAL)   # шкала-повзунок
days.pack()                                      # days.get(), days.set(7)

from tkinter import ttk
box = ttk.Combobox(window, values=["0%", "10%"], state="readonly")
box.current(0)                                   # box.get() → "0%"
box.pack()
Миттєвий перерахунокПараметр command=calculate у Radiobutton, Checkbutton і Scale та box.bind("<<ComboboxSelected>>", calculate) викликають функцію одразу після зміни. Тому функцію оголошують як def calculate(*args): — Scale і Combobox передають їй додатковий аргумент.
