Контейнери в HTML

Щоб розташовувати частини сторінки, їх групують у контейнери. <div> — універсальний контейнер. Семантичні теги ще й пояснюють браузеру та пошуковикам, що в них:

ТегПризначення
<header>Шапка: логотип, назва, меню
<nav>Навігація (меню)
<main>Основний вміст
<section>Тематичний розділ
<article>Самостійний матеріал: стаття, картка товару
<aside>Бічна панель
<footer>Підвал: контакти, авторські права

Модуль гнучких блоків Flexbox

Flexbox — модуль CSS для розташування елементів у ряд або стовпчик з гнучким вирівнюванням і розподілом простору. Вмикається для контейнера: display: flex; — і всі його дочірні елементи стають flex-елементами.

Властивість контейнераЗначенняЩо робить
flex-directionrow | columnНапрямок: у ряд / у стовпчик
justify-contentflex-start | center | space-between | space-aroundВирівнювання вздовж головної осі
align-itemsstretch | center | flex-startВирівнювання поперек осі
flex-wrapwrapПереносити на новий рядок, якщо не вміщаються
gap20pxПроміжок між елементами
.container {
    display: flex;
    justify-content: space-between;   /* рівні проміжки між блоками */
    align-items: center;              /* по центру вертикально */
    gap: 20px;
}
.box {
    width: 100px;
    height: 100px;
    background: #1E7A55;
}
Центр екранаКласичне завдання — поставити блок рівно в центр: body { height: 100vh; display: flex; justify-content: center; align-items: center; }. 100vh — 100 % висоти вікна.

Макет, цільова аудиторія, технічне завдання

Макет сайту — схема розташування основних блоків сторінки: шапка, меню, основний вміст, бічна панель, підвал. Спочатку — ескіз на папері або у Figma/Canva (wireframe), потім — верстка.

Цільова аудиторія (ЦА) — група людей, для яких створюється сайт. Від неї залежать дизайн, мова, вміст і функції.

Опишіть ЦА: вік, інтереси, звідки заходять (смартфон чи ПК), що хочуть знайти. Сайт бібліотеки для першокласників і для студентів виглядатиме зовсім по-різному.

Технічне завдання (ТЗ) — документ, у якому замовник і розробник фіксують усі вимоги до сайту.

  • Мета сайту — навіщо він;
  • Цільова аудиторія;
  • Структура — перелік сторінок і розділів;
  • Функціонал — форма, галерея, пошук, мапа;
  • Дизайн — кольори, шрифти, стиль, адаптивність до смартфонів;
  • Вміст — тексти, фото: хто готує;
  • Терміни і бюджет.
