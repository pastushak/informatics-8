Цикл for і функція range()

Цикл — алгоритмічна структура, яка повторює набір команд кілька разів.

for i in range(5):
    print("Привіт!", i)
Привіт! 0 Привіт! 1 Привіт! 2 Привіт! 3 Привіт! 4
ЗаписЗначення i
range(5)0, 1, 2, 3, 4 (до 5, не включно)
range(1, 6)1, 2, 3, 4, 5
range(2, 11, 2)2, 4, 6, 8, 10 (крок 2)
range(10, 0, -1)10, 9, …, 1
for letter in "Python":     # по символах рядка
    print(letter)

Накопичення: сума і кількість

n = int(input("Введіть N: "))
s = 0                        # спочатку сума нуль
for i in range(1, n + 1):
    s += i                   # додаємо кожне число
print(f"Сума чисел від 1 до {n}: {s}")
a = int(input("a = "))
b = int(input("b = "))
gcd = 1
for i in range(1, min(a, b) + 1):
    if a % i == 0 and b % i == 0:
        gcd = i              # запам'ятовуємо останній спільний дільник
print("НСД =", gcd)

Цикл while

Цикл while — повторює команди, поки умова істинна. Використовують, коли кількість повторень наперед невідома.

password = ""
while password != "python":
    password = input("Пароль: ")
print("Доступ дозволено")
money = 1000
years = 0
while money < 2000:          # скільки років, щоб подвоїти вклад під 10 %?
    money = money * 1.1
    years += 1
print(years)
Нескінченний циклЯкщо умова while ніколи не стане хибною, програма «зависне». Зупинити: Ctrl+C або кнопка Stop. break достроково виходить з циклу.
