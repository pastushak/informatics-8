Зразок: сума від 1 до N

from tkinter import *

def calculate_sum():
    n = int(entry.get())
    s = 0
    for i in range(1, n + 1):
        s += i
    result.config(text=f"Сума чисел: {s}")

window = Tk()
window.title("Обчислення суми чисел")
window.geometry("300x150")
Label(window, text="Введіть число N:").pack()
entry = Entry(window); entry.pack()
Button(window, text="Обчислити", command=calculate_sum).pack(pady=5)
result = Label(window, text=""); result.pack()
window.mainloop()

Складання програмних проєктів з командами повторення

Мета: складати програми з циклами for і while та графічним інтерфейсом.

Заготовки до роботи

⬇ Файли ПР №25pr25.zipАрхів з .py-файлами. Розпакуйте і відкрийте в IDLE / Thonny / VS Code. Місця, де треба дописати код, позначені # TODO.
  1. Завдання 1. Сума від 1 до N

    За зразком.

  2. Завдання 2. Сума від A до B

    Два поля (A і B), кнопка, мітка з сумою чисел від A до B включно. Якщо A > B — повідомлення «A має бути менше за B».

  3. Завдання 3. НСД перебором

    Вікно «Обчислення НСД (перебір)»: поля a і b, кнопка викликає calculate_gcd():

    1. Визначте менше з двох чисел: min(a, b).
    2. Перевірте всі числа від 1 до min, які ділять і a, і b.
    3. Останнє (найбільше) таке число — НСД.
  4. Завдання 4. Рахунок туристів

    Туристична група: користувач вводить кількість туристів; для кожного (цикл) вводить вік (через input або діалог). Порахуйте, скільки дітей (до 18) і дорослих, і загальну вартість квитків: дитячий — 150 грн, дорослий — 250 грн.

  5. Завдання 5. while додатково

    Програма «Вгадай число»: комп'ютер загадує random.randint(1, 100), користувач вгадує в консолі з підказками «більше / менше», поки не вгадає. Виведіть кількість спроб.
