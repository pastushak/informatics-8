Команда розгалуження

Програма вчиться вибирати: якщо умова істинна — одне, інакше — інше. Оператори if, elif, else, вкладені умови і повідомлення для користувача.

Оператор if і else

Розгалуження — алгоритмічна структура, у якій залежно від умови виконується одна або інша послідовність команд.

t = float(input("Температура: "))
if t < 0:
    print("Мороз! Одягніть шапку")
else:
    print("Морозу немає")
print("Гарного дня")        # виконається завжди
  1. Після умови — двокрапка :.
  2. Команди всередині — з відступом 4 пробіли (Tab).
  3. else не має умови і стоїть на рівні if.
  4. Рядок без відступу — вже поза розгалуженням.

Кілька варіантів: elif

ph = float(input("Значення pH: "))
if ph < 7:
    print("Кислий")
elif ph == 7:
    print("Нейтральний")
else:
    print("Лужний")

elif («else if») перевіряється, лише якщо всі попередні умови хибні. Виконується перша істинна гілка, решта пропускаються.

mark = int(input("Бал (1–12): "))
if mark >= 10:
    print("Високий рівень")
elif mark >= 7:
    print("Достатній рівень")
elif mark >= 4:
    print("Середній рівень")
else:
    print("Початковий рівень")

Вкладені умови і розгалуження у вікні

price = float(input("Ціна: "))
money = float(input("Гроші: "))
if money >= price:
    change = money - price
    if change == 0:
        print("Без решти")
    else:
        print(f"Решта: {round(change, 2)} грн")
else:
    print(f"Не вистачає {round(price - money, 2)} грн")

У Tkinter результат виводять у мітку, а колір вікна можна змінювати залежно від гілки: window.configure(bg="lightgreen").
