Покликання (гіперпосилання)

Покликання — елемент, клацнувши на який, користувач переходить на іншу сторінку, файл або місце сторінки. Створюється тегом <a> з атрибутом href.

<a href="https://uk.wikipedia.org">Вікіпедія</a>            <!-- зовнішнє -->
<a href="about.html">Про мене</a>                          <!-- інша сторінка сайту -->
<a href="#contacts">До контактів</a>                       <!-- якір на цій сторінці -->
<a href="mailto:teacher@school.ua">Написати листа</a>
<a href="https://youtube.com" target="_blank">Відкрити в новій вкладці</a>

Якір: елементу дають атрибут id="contacts", а посилання веде на #contacts.

Форма — елемент <form>, через який користувач вводить і надсилає дані: реєстрація, пошук, опитування.

ЕлементВигляд

type="email", "password", "number", "date"Пошта, пароль (крапки), число, дата
type="checkbox" / "radio"Прапорець / перемикач (один з кількох)
<select> + <option>Випадний список
<textarea>Багаторядкове поле

Каскадні таблиці стилів (CSS)

CSS (Cascading Style Sheets) — мова опису зовнішнього вигляду сторінки: кольори, шрифти, відступи, розташування елементів.

селектор {
    властивість: значення;
}
h1 {
    color: #1E7A55;
    text-align: center;
}
Спосіб підключенняПрикладКоли
Вбудований (inline)<p style="color:red">Рідко, для одного елемента
Внутрішній<style>…</style> у headОдна сторінка
Зовнішній файл ✔<link rel="stylesheet" href="style.css">Сайт з кількох сторінок — один стиль для всіх
СелекторКого вибирає
pУсі абзаци (за тегом)
.cardЕлементи з class="card" (клас — для багатьох)
#logoЕлемент з id="logo" (id — унікальний)
nav aПосилання всередині nav
a:hoverПосилання під курсором

«Каскадні» — бо до одного елемента можуть застосовуватись кілька правил; перемагає точніше (id > клас > тег) або пізніше записане.

Інструменти розробника

У кожному браузері є інструменти розробника (DevTools): F12 або ПКМ → Переглянути код (Inspect).

ElementsHTML-код сторінки і CSS обраного елемента. Значення можна змінювати «на льоту» й одразу бачити результат (зміни зникнуть після оновлення).
ConsoleПовідомлення про помилки JavaScript.
NetworkЯкі файли завантажує сторінка і скільки часу.
Режим пристроюCtrl+Shift+M — подивитися, як сайт виглядає на смартфоні.
СпробуйтеВідкрийте будь-який сайт, натисніть F12, оберіть інструментом-стрілкою заголовок і змініть у панелі Styles його колір. Це безпечно — змінюється лише ваша копія сторінки.
