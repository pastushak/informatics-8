Повторне використання коду

Шапку і підвал не треба писати заново: скопіюйте їх з index.html у нові сторінки і змініть лише клас active та <title>. Картки напрямків можна оформити тими самими класами .cards і .card — стилі вже є.

B1
Робимо · Практична робота

Сторінки «Напрямки» і «Контакти», публікація

Мета: завершити багатосторінковий сайт, протестувати переходи між сторінками та опублікувати його.

Заготовки до роботи

⬇ Каркас сайту «Подорожі»travels-start.zipЯкщо минулого уроку не встигли, почніть із цього каркаса.
  1. Сторінка «Напрямки»

    Скопіюйте шапку й підвал з index.html, змініть title на «Подорожі — Напрямки» і active. Основний вміст — 3–6 карток напрямків: фото, назва, опис, ціна.

  2. Сторінка «Контакти»

    Шапка, підвал, форма зворотного зв'язку (ім'я, email, повідомлення, прапорець підписки, кнопка) і блок контактів: адреса, телефон, години роботи. За бажанням — Google Мапа (Поділитися → Вставити карту → код iframe).

  3. Стилі нових елементів
    .price { color: #FF6F61; font-weight: 700; font-size: 18px; }
.contact { max-width: 600px; margin: 40px auto; padding: 0 20px; }
.contact-form { display: flex; flex-direction: column; gap: 8px; }
.contact-form input, .contact-form textarea {
    padding: 10px; border: 1px solid #ccc; border-radius: 6px; font: inherit;
}
.contact-form button {
    margin-top: 10px; padding: 12px; background: #FF6F61; color: #fff;
    border: none; border-radius: 6px; cursor: pointer;
}
.contact-form button:hover { background: #e85a4f; }
  4. Тестування
    • Пройдіть по всіх пунктах меню з кожної сторінки (3 × 3 = 9 переходів).
    • Перевірте на «смартфоні» в DevTools.
    • Валідатор для всіх трьох сторінок.
  5. Публікація

    Репозиторій travels → завантажте всі файли й папку img → Settings → Pages. Перевірте переходи вже онлайн.

Здача роботи
  1. Посилання

    Адреса сайту і репозиторію.

  2. Здайте в Classroom

    Завдання «Проєкт Подорожі» → Здати.
