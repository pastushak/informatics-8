Виведення: print() і f-рядки

name = "Оля"
age = 14
print("Привіт,", name)                  # через кому — з пробілами
print("Привіт, " + name + "!")         # склеювання рядків
print(f"{name}, тобі {age} років")      # f-рядок
print("А", "Б", "В", sep="-")          # свій роздільник
print("Без переходу", end=" ")          # без нового рядка
print("на новий рядок")
Привіт, Оля Привіт, Оля! Оля, тобі 14 років А-Б-В Без переходу на новий рядок

f-рядок — рядок з літерою f перед лапками, у який у фігурних дужках { } підставляються значення змінних і виразів: f"Площа: {a * b} м²".

Введення і присвоєння

weight = float(input("Ваша вага, кг: "))
time = int(input("Тривалість бігу, хв: "))
calories = 10 * weight * time / 60   # приклад формули
print(f"За {time} хв ви спалите {calories} ккал")

Присвоєння — запис значення у змінну: змінна = вираз. Спочатку обчислюється права частина, потім результат записується в змінну зліва.

Tkinter: Label, Entry і розміщення

from tkinter import *

window = Tk()
window.title("Вітання")
window.geometry("400x150")

label = Label(window, text="Введіть ім'я:", font=("Arial", 14))
label.pack(pady=10)                  # мітка — текст у вікні

entry = Entry(window, font=("Arial", 14))
entry.pack()                         # поле введення

window.mainloop()
Параметр LabelЗначення
textТекст
font=("Arial", 18)Шрифт і розмір
fg="blue", bg="white"Колір тексту і фону
image=imgЗображення: img = PhotoImage(file="cat.png")
МенеджерЯк розміщуєПриклад
pack()Один за одним (зверху вниз або side=LEFT)label.pack(pady=30)
place()За точними координатами в пікселяхentry.place(x=200, y=80)
grid()У таблиці рядків і стовпцівentry.grid(row=0, column=1, padx=5)
Не змішуйтеВ одному вікні використовуйте лише один спосіб розміщення: або pack, або grid, або place.
