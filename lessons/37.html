Перша програма

Функція print() виводить на екран те, що в дужках. Текст беруть у лапки, числа і вирази — без лапок. Кілька значень розділяють комою — між ними з'явиться пробіл.

print("Сума:", 45 + 15)
print("Частка:", 45 / 15)
Сума: 60 Частка: 3.0

Знайомство із середовищем розробки IDE

Мета: навчитися створювати, запускати і зберігати програми Python у середовищі розробки та онлайн.

Заготовки до роботи

⬇ Файли ПР №19pr19.zipАрхів з .py-файлами. Розпакуйте і відкрийте в IDLE / Thonny / VS Code. Місця, де треба дописати код, позначені # TODO.
  1. Завдання 1. Перша програма

    Відкрийте IDLE, Thonny або VS Code. Створіть папку python8, у ній файл welcome.py:

    print("Hello, Python!")
print("Мене звати ...")   # своє ім'я

    Запустіть. Запишіть: які частини вікна IDE ви використали, що з'явилося в консолі.

  2. Завдання 2. Математичні операції

    Новий файл math_operations.py:

    a = 45
b = 15
print("Сума:", a + b)
print("Різниця:", a - b)
print("Добуток:", a * b)
print("Частка:", a / b)

    Запустіть, потім змініть значення a і b (наприклад, 7 і 2) і запустіть знову. Що змінилося?

  3. Завдання 3. Онлайн-середовище

    Відкрийте onlinegdb.com → Language: Python 3. Напишіть:

    print("Hello, OnlineGDB!")
name = input("Введіть ваше ім'я: ")
print("Привіт,", name, "!")

    Натисніть Run, введіть ім'я у вікні внизу і натисніть Enter.

  4. Поділіться кодом

    У OnlineGDB натисніть Share → скопіюйте посилання. Також натисніть Download і відкрийте завантажений файл у своєму редакторі.

  5. Дайте відповіді
    • Що робить кожна команда print() у завданні 2?
    • Чим відрізняється результат a / b від a * b за типом числа?
Здача роботи
