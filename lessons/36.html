Середовище розробки (IDE)

Середовище для написання коду (IDE, інтегроване середовище розробки) — програма, яка об'єднує інструменти для написання, запуску, перевірки і виправлення коду.

Редактор кодуПідсвічує синтаксис, робить автовідступи, підказує назви команд.
ТрансляторКомпілятор або інтерпретатор перетворює код на команди для комп'ютера.
Відладчик (дебагер)Дозволяє виконувати програму покроково і бачити значення змінних — щоб знайти помилку.
Керування файламиОрганізовує файли великого проєкту.
IDEОсобливості
IDLEВстановлюється разом з Python. Просте, для початківців
ThonnyСтворене для навчання: показує, як змінюються змінні під час виконання
Visual Studio CodeБезкоштовний, легкий, підтримує багато мов через розширення
PyCharmПотужне середовище саме для Python
Онлайн: OnlineGDB, Programiz, ReplitПрацюють у браузері, нічого не треба встановлювати
Немає комп'ютера з Python?Консольні програми (з print та input) можна запускати онлайн: onlinegdb.com (оберіть Language: Python 3), programiz.com/python-programming/online-compiler, на смартфоні — застосунок Pydroid 3. Програми з вікнами Tkinter онлайн не працюють — у Pydroid 3 вони запускаються.

Транслятори: компілятори та інтерпретатори

Транслятор — програма, яка перетворює код, написаний програмістом мовою програмування, у машинний код, зрозумілий процесору.

КомпіляторПерекладає всю програму наперед і створює виконуваний файл (.exe). Як переклад книжки перед тим, як її читатимуть. Програма потім працює швидко. Мови: C, C++, Go, Rust.
ІнтерпретаторПерекладає і виконує програму рядок за рядком. Як синхронний перекладач на зустрічі. Зручно для навчання: помилку видно одразу. Мови: Python, JavaScript, PHP.

Python — інтерпретована мова. Якщо в 10-му рядку помилка, перші 9 рядків уже виконаються, а потім з'явиться повідомлення про помилку з номером рядка.

Програмний проєкт

Програмний проєкт — сукупність файлів (код, зображення, дані, налаштування), об'єднаних в одну папку, які разом утворюють програму.

  1. Постановка задачіщо має робити програма і для кого
  2. Проєктуванняалгоритм, інтерфейс, структура файлів
  3. Програмуваннянаписання коду
  4. Тестування і налагодженняпошук і виправлення помилок
  5. Впровадження і підтримкапередача користувачам, оновлення

Файли Python мають розширення .py. Назви — латиницею, без пробілів: welcome.py, math_operations.py.
