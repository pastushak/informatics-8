Зразок: кнопка підтвердження

from tkinter import *
from tkinter import messagebox

def ask_confirmation():
    response = messagebox.askyesno("Підтвердження", "Ви впевнені, що хочете продовжити?")
    if response:
        button_confirm.config(text="Продовжено", bg="#2ECC71")
    else:
        button_confirm.config(text="Скасовано", bg="#E74C3C")

window = Tk()
window.title("Види повідомлень")
window.geometry("400x300")
button_confirm = Button(window, text="Підтвердження", font=("Arial", 12), bg="#3498DB", fg="white", command=ask_confirmation)
button_confirm.pack(pady=10)
window.mainloop()
Немає комп'ютера з Python?Консольні програми (з print та input) можна запускати онлайн: onlinegdb.com (оберіть Language: Python 3), programiz.com/python-programming/online-compiler, на смартфоні — застосунок Pydroid 3. Програми з вікнами Tkinter онлайн не працюють — у Pydroid 3 вони запускаються.

Робимо · Практична робота №26

Складання програмних проєктів

Мета: використовувати діалогові вікна messagebox, обробку помилок і коментарі в програмах з графічним інтерфейсом.

Заготовки до роботи

⬇ Файли ПР №26pr26.zipАрхів з .py-файлами. Розпакуйте і відкрийте в IDLE / Thonny / VS Code. Місця, де треба дописати код, позначені # TODO.
  1. Завдання 1. Види повідомлень

    Вікно 400×300 з міткою і чотирма кнопками (Arial 12, білий текст):

    • Info (фон #2ECC71) → show_info() → showinfo;
    • Warning (#F39C12) → showwarning;
    • Error (#E74C3C) → showerror;
    • Confirm (#3498DB) → askyesno: «Продовжено» зеленим або «Скасовано» червоним.
  2. Завдання 2. Перевірка віку для доступу

    Поле для віку і кнопка. Якщо менше 18 — showerror «Доступ заборонено»; інакше — showinfo «Ласкаво просимо!». Якщо введено не число — showwarning через try / except ValueError.

  3. Завдання 3. Запит на вихід

    Кнопка «Вийти»: askyesno("Вихід", "Закрити програму?") → якщо так — window.destroy().

  4. Коментарі

    У кожному файлі: коментар-заголовок (що робить програма, автор) і коментарі до кожної функції.
