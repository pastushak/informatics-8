Логічний тип і операції відношень

Логічний тип (bool) — тип даних, що має лише два значення: True (істина) і False (хиба).

ОпераціяЗмістПрикладРезультат
==дорівнює5 == 5True
!=не дорівнює5 != 3True
>, <більше, менше3 > 7False
>=, <=не менше, не більше7 >= 7True
= чи === — присвоєння (записати значення), == — порівняння (перевірити рівність). Це найчастіша помилка початківців.
n = 8
is_even = n % 2 == 0
print(is_even)          # True
print("кіт" < "сир")    # рядки порівнюються за абеткою → True

Випадкові числа і bool у Tkinter

import random
num = random.randint(1, 10)      # ціле від 1 до 10 включно
print(num)
from tkinter import *

def check():
    n = int(entry.get())
    result.config(text=f"Парне: {n % 2 == 0}")

window = Tk()
window.title("Перевірка на парність")
entry = Entry(window); entry.pack(pady=5)
Button(window, text="Перевірити", command=check).pack()
result = Label(window, text="Парне: ?"); result.pack(pady=5)
window.mainloop()
