Проєкт «Розв'язування квадратних рівнянь»: інтерфейс

Квадратне рівняння ax² + bx + c = 0 (a ≠ 0) розв'язують через дискримінант:

ДискримінантКорені
D = b² − 4ac
D > 0два корені: x = (−b ± √D) / 2a
D = 0один корінь: x = −b / 2a
D < 0дійсних коренів немає
# Перевірте алгоритм у консолі
from math import sqrt
a, b, c = 1, -3, 2
d = b ** 2 - 4 * a * c
if d > 0:
    print((-b + sqrt(d)) / (2 * a), (-b - sqrt(d)) / (2 * a))
elif d == 0:
    print(-b / (2 * a))
else:
    print("Коренів немає")

Інтерфейс

  • Вікно 500×350, без зміни розміру, заголовок «Розв'язування квадратних рівнянь», свій колір фону.
  • Заголовок-мітка з виглядом рівняння.
  • Три поля Entry для a, b, c (зручно — у Frame з grid).
  • Кнопки «Розрахувати» і «Очистити».
  • Мітка для результату.

Підключення модулів:

from tkinter import *
from tkinter import messagebox   # вікна повідомлень
from math import sqrt             # квадратний корінь

Frame — невидимий контейнер у вікні Tkinter для групування елементів (як div у HTML). Усередині Frame можна використовувати grid, навіть якщо вікно розміщує через pack.

Інтерфейс програми «Квадратні рівняння»

Мета: спроєктувати і створити вікно програми з полями для коефіцієнтів, кнопками і міткою результату.

  1. Перевірте алгоритм

    Запустіть консольний варіант з теорії на трьох рівняннях: x² − 3x + 2, x² + 2x + 1, x² + 1. Чи збігаються відповіді з розв'язаними в зошиті?

  2. Ескіз вікна

    Намалюйте на папері або в Canva, де будуть поля, кнопки і результат.

  3. Створіть вікно

    Файл quadratic.py: модулі, вікно з властивостями, заголовок-мітка, три поля для a, b, c, кнопки «Розрахувати» і «Очистити» (поки з порожніми функціями def solve(): pass), мітка результату.

  4. Запустіть

    Вікно має відкриватися без помилок, а всі елементи — бути на своїх місцях. Кольори і шрифти оберіть самі.

Здача роботи
  1. Проміжна здача

    Файл quadratic.py + скріншот вікна.

  2. Здайте в Classroom

    «Проєкт 1 — етап 1» → Здати.
