Модуль math

import math

print(math.sqrt(16))      # квадратний корінь → 4.0
print(math.pi)            # число π → 3.141592653589793
print(math.ceil(4.2))     # округлення вгору → 5
print(math.floor(4.8))    # округлення вниз → 4
print(round(3.14159, 2))  # округлення до 2 знаків → 3.14 (вбудована функція)
print(abs(-7))            # модуль числа → 7 (вбудована функція)

Площа кола: S = math.pi * r ** 2. Гіпотенуза: c = math.sqrt(a**2 + b**2).

Tkinter: кнопки і обробка введення

from tkinter import *

def calc_area():                       # функція, яку викличе кнопка
    a = float(entry_a.get())           # .get() — текст з поля
    b = float(entry_b.get())
    result.config(text=f"Площа: {a * b}")   # змінюємо текст мітки

window = Tk()
window.title("Площа прямокутника")
window.geometry("300x200")

Label(window, text="Довжина:").pack()
entry_a = Entry(window); entry_a.pack()
Label(window, text="Ширина:").pack()
entry_b = Entry(window); entry_b.pack()

Button(window, text="Обчислити", command=calc_area).pack(pady=5)
result = Label(window, text="")
result.pack()

window.mainloop()

def — створює функцію — іменований блок команд. Команди функції пишуть з відступом 4 пробіли.

У Button(..., command=calc_area) пишемо назву функції без дужок — вона виконається при натисканні. Змінити властивості вікна: window.configure(bg="green"), window.title("Зелений").
