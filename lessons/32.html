Текст і типографіка у векторному редакторі. Ефекти та фільтри

Типографіка

Типографіка — мистецтво роботи з текстом: вибір шрифтів, їхній розмір, колір, інтервали і розташування.

Група шрифтівВиглядДе доречний
Із засічками (serif)Lora, Times New Roman, PT SerifОфіційні, класичні, книжкові проєкти
Без засічок (sans-serif)Roboto, Montserrat, ArialСайти, інтерфейси — найкраще читаються на екрані
Рукописні (script)Caveat, Marck ScriptТворчі проєкти, листівки — лише для акцентів
Декоративні (display)Unbounded, ComfortaaВеликі заголовки
  1. Не більше 2–3 шрифтів в одному дизайні.
  2. Ієрархія розмірів: заголовки 28–36, підзаголовки 20–24, текст 14–18, підписи 12.
  3. Контраст: темний текст на світлому фоні або білий на темному.
  4. Декоративні шрифти — лише для заголовків, не для довгого тексту.
  5. Вирівнювання ліворуч — найзручніше для читання абзаців; по центру — для коротких заголовків.

Шрифтова пара — поєднання двох шрифтів, що гармонують: зазвичай акцентний для заголовків + нейтральний для тексту. Приклади: Montserrat + Roboto; Lora + Open Sans; Unbounded + Golos Text.

Інтервали: між літерами (трекінг, у Canva — «Інтервал»), між рядками (міжрядковий, 1,4–1,6 для тексту). Тісний текст важко читати, а надто розріджений «розсипається».

Ефекти та фільтри

ТіньДодає об'єму, «піднімає» кнопки і картки над фоном.
Обведення текстуРобить текст помітним на строкатому фоні.
ПрозорістьНакладки на фото, водяні знаки.
ГрадієнтПлавний перехід кольорів — сучасні фони і кнопки.
Фільтри фотоЯскравість, контраст, насиченість, ч/б, розмиття, віньєтка.
Ефекти тексту в CanvaТінь, підйом, контур, неон, викривлення.

У Canva: текст → Ефекти; фото → Редагувати → Налаштувати / Фільтри; фігури → Прозорість, кольори → Градієнт.

МіраЕфекти — як спеції: трохи — смачно, забагато — не їстівно. Одна тінь для карток і один тип ефекту для заголовків на весь сайт.
