Проєкт «Подорожі»: багатосторінковий сайт. Головна сторінка

Другий проєкт — сайт туристичної агенції з трьох сторінок: Головна, Напрямки, Контакти. Вчимося пов'язувати сторінки меню і використовувати один CSS-файл для всього сайту.

Багатосторінковий сайт

У багатосторінковому сайті кожна сторінка — окремий HTML-файл, а пов'язує їх однакове меню. Усі сторінки підключають один спільний style.css — змінюєте колір в одному місці, і він змінюється всюди.

Цільова аудиторіяЛюди, які люблять подорожувати; туристичні агенції; ті, хто шукає інформацію про популярні напрямки.
ФункціїПрезентація напрямків; контакти; підписка на новини та акції; форма зворотного зв'язку.
СтильТемно-сірий #333, білий, кораловий #FF6F61, світло-сірий #FAFAFA; шрифт Arial.
Активний пункт менюНа кожній сторінці додайте клас active посиланню на поточну сторінку — відвідувач бачитиме, де він.

Робимо · Практична робота

Головна сторінка сайту «Подорожі»

Мета: створити структуру багатосторінкового сайту, головну сторінку з меню, банером, картками переваг і спільний файл стилів.

  1. Структура проєкту

    Папка travels: index.html, destinations.html, contact.html, style.css, папка img з фото (logo.png, hero.jpg, 3 фото для карток).

  2. Розмітка головної сторінки

    Чотири блоки: header.head (логотип + меню), section.hero (привітання), section.intro (три картки «Чому слід обрати нас»), footer.footer.

    <!DOCTYPE html>
<html lang="uk">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Подорожі — Головна</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <header class="head">
        <img src="img/logo.png" class="logo" alt="логотип">
        <nav class="menu">
            <ul class="menu-links">
                <li class="menu-item"><a href="index.html" class="menu-item-link active">Головна</a></li>
                <li class="menu-item"><a href="destinations.html" class="menu-item-link">Напрямки</a></li>
                <li class="menu-item"><a href="contact.html" class="menu-item-link">Контакти</a></li>
            </ul>
        </nav>
    </header>

    <section class="hero">
        <div class="hero-info">
            <h1 class="hero-title">Ласкаво просимо до світу подорожей!</h1>
            <p class="hero-text">Відкрийте для себе нові місця та враження</p>
        </div>
    </section>

    <section class="intro">
        <h2 class="intro-title">Чому слід обрати нас</h2>
        <div class="cards">
            <div class="card">
                <img src="img/destinations.jpg" alt="Найкращі напрямки" class="card-img">
                <div class="card-content">
                    <h3 class="card-title">Найкращі напрямки для вашої подорожі</h3>
                    <ul class="card-list">
                        <li>Екзотичні острови</li>
                        <li>Історичні міста</li>
                        <li>Культурні центри</li>
                    </ul>
                </div>
            </div>
            <!-- ще дві картки: «Індивідуальні тури», «Відмінний сервіс» -->
        </div>
    </section>

    <footer class="footer">
        <p>© 2026 Подорожі · Коломия · info@travel.ua</p>
    </footer>
</body>
</html>
  3. Три картки переваг
    • «Найкращі напрямки для вашої подорожі»: екзотичні острови, історичні міста, культурні центри;
    • «Індивідуальні тури під ваші потреби»: сімейні тури, романтичні подорожі, екстремальні пригоди;
    • «Відмінний сервіс»: підтримка 24/7, зручне бронювання, гарантована якість.
  4. Спільні стилі
    * { box-sizing: border-box; }
body { margin: 0; font-family: Arial, Helvetica, sans-serif; color: #333; }
/* шапка і меню — спільні для всіх сторінок */
.head {
    display: flex;
    justify-content: space-between;
    align-items: center;
    background: #333;
    padding: 10px 40px;
}
.logo { height: 50px; }
.menu-links { display: flex; gap: 10px; list-style: none; margin: 0; padding: 0; }
.menu-item-link {
    color: #fff;
    text-decoration: none;
    padding: 8px 16px;
    border-radius: 5px;
}
.menu-item-link:hover, .menu-item-link.active { background: #FF6F61; }
/* головний банер */
.hero {
    height: 70vh;
    display: flex;
    justify-content: center;
    align-items: center;
    background: url("img/hero.jpg") center / cover;
    text-align: center;
}
.hero-info { background: rgba(0, 0, 0, .5); color: #fff; padding: 30px 40px; border-radius: 12px; }
.hero-title { font-size: 44px; margin: 0 0 10px; }
/* переваги */
.intro { padding: 60px 20px; text-align: center; background: #FAFAFA; }
.cards { display: flex; justify-content: center; flex-wrap: wrap; gap: 24px; }
.card {
    width: 300px;
    background: #fff;
    border-radius: 12px;
    overflow: hidden;
    box-shadow: 0 4px 12px rgba(0, 0, 0, .1);
    text-align: left;
}
.card-img { width: 100%; height: 180px; object-fit: cover; }
.card-content { padding: 16px; }
.card-title { color: #FF6F61; margin-top: 0; }
/* підвал */
.footer { background: #333; color: #fff; text-align: center; padding: 20px; }
  5. Перевірте

    Меню веде на три сторінки (дві поки порожні — це нормально, буде помилка «файл не знайдено», якщо їх не створено; створіть порожні файли). Банер займає 70 % висоти екрана, картки переносяться на вузькому екрані.

Домашнє завдання

  1. Доробіть головну сторінку. Напишіть власний текст привітання (2–3 речення) про агенцію.
  2. Оберіть 3–6 туристичних напрямків для сторінки «Напрямки» (можна українські: Карпати, Львів, Кам'янець-Подільський) і підготуйте по 2–3 речення опису кожного.
