Нагадування: Flexbox для навігації і карток

<nav class="nav">
    <div class="logo">Логотип</div>
    <div class="nav-links">
        <a class="nav-links-item" href="#">Головна</a>
        <a class="nav-links-item" href="#">Про нас</a>
        <a class="nav-links-item" href="#">Контакти</a>
    </div>
</nav>
.nav {
    display: flex;
    justify-content: space-between;
    align-items: center;
    background: #333;
    padding: 10px 20px;
}
.nav-links-item {
    color: white;
    text-decoration: none;     /* без підкреслення */
    padding: 8px 12px;
}
.nav-links-item:hover {
    background: #575757;
    border-radius: 5px;
}

B1
Робимо · Практична робота №14

Додавання елементів на сайт

Мета: навчитися розташовувати елементи за допомогою Flexbox: блоки в ряд і в стовпчик, навігаційна панель, картка профілю.

Заготовки до роботи

⬇ П'ять файлів завдань Flexboxpr14-flexbox.zipАрхів. Розпакуйте: ПКМ → «Видобути все», відкрийте папку у VS Code або Блокноті.
  1. Завдання 1. Три блоки в ряд по центру

    Створіть div.container з трьома div.box (100×100, різні кольори). Для body: height: 100vh; display: flex; justify-content: center; align-items: center;. Для контейнера: display: flex; gap: 20px;.

  2. Завдання 2. Рівні проміжки

    Скопіюйте файл. Контейнеру задайте ширину 600px і justify-content: space-between, потім спробуйте space-around. Скріншоти обох.

  3. Завдання 3. Стовпчик

    Ті самі блоки — flex-direction: column; align-items: center;.

  4. Завдання 4. Навігаційна панель

    За прикладом з теорії: логотип ліворуч, 4 пункти меню праворуч (Головна, Про нас, Послуги, Контакти). body { margin: 0; font-family: Arial; }, темний фон, білий текст, :hover з фоном #575757 і заокругленням 5px.

  5. Завдання 5. Картка профілю
    <div class="profile-card">
    <img src="photo.jpg" alt="Фото профілю" class="profile-image">
    <div class="profile-info">
        <h2 class="profile-name">Ім'я Користувача</h2>
        <p class="profile-description">Короткий опис: захоплення, мрії.</p>
        <div class="social-links">
            <a href="#" class="social-link">Instagram</a>
            <a href="#" class="social-link">YouTube</a>
        </div>
    </div>
</div>

    body — картка в центрі екрана. .profile-card: display: flex; flex-direction: column; align-items: center;, ширина 300px, білий фон, тінь, заокруглення. .profile-image: 100×100px, border-radius: 50%, object-fit: cover. .social-links: display: flex; gap: 10px. Замість фото людини можна взяти аватар-малюнок.

    Додайте скріншоти кожного завдання → Здати.

Якщо щось не виходить
Блоки не стають у ряд

display: flex треба задавати контейнеру (батьківському елементу), а не самим блокам.

Не центрується по вертикалі

Контейнеру потрібна висота: для body — height: 100vh.

Фото в картці розтягнуте

Додайте object-fit: cover;.
