Хостинг

Хостинг — послуга розміщення вебсайту на сервері, підключеному до інтернету 24/7, щоб сайт могли бачити інші користувачі. Компанії, що її надають, — хостинг-провайдери.

ВидСутьДля кого
Безкоштовний статичнийHTML/CSS/JS без сервера: GitHub Pages, Netlify, VercelНавчальні проєкти, портфоліо
Віртуальний (shared)Один сервер на багато сайтівНевеликі сайти, блоги
VPSВіртуальний «власний» серверСередні проєкти
Виділений серверОкремий фізичний серверВеликі сайти
ХмарнийРесурси масштабуються за потреби: AWS, Google Cloud, AzureСервіси з мільйонами користувачів

Доменне ім'я — зручна для людини адреса сайту (school.if.ua) замість IP-адреси сервера. Домен купують у реєстратора, а на GitHub Pages безкоштовно дається адреса ім'я.github.io.

Інструменти координації роботи команди

Сайти й програми створюють команди: дизайнер, верстальник, програміст, тестувальник, менеджер. Щоб усе встигнути, використовують методи керування проєктами.

KanbanДошка з колонками «Треба зробити → Виконується → Готово». Кожна задача — картка, яку пересувають. Видно, хто чим зайнятий. Сервіси: Trello, Google Tasks, GitHub Projects.
ScrumРобота короткими циклами — спринтами (1–4 тижні). Щодня — коротка зустріч (що зробив, що робитиму, що заважає). Наприкінці спринту — демонстрація результату і ретроспектива.
КомунікаціяЧати (Slack, Teams, Telegram), відеозустрічі, спільні документи.

Система контролю версій. Git і GitHub

Система контролю версій (VCS) — програма, яка зберігає історію всіх змін файлів проєкту: що змінено, ким і коли, — і дозволяє повернутися до будь-якої попередньої версії.

Найпопулярніша — Git. GitHub — онлайн-сервіс, де зберігають Git-проєкти і працюють над ними разом.

ПоняттяЩо означає
Репозиторій (repository)Папка проєкту з усією історією змін
Коміт (commit)Збережений «знімок» змін з коротким описом: «Додав форму реєстрації»
Гілка (branch)Паралельна лінія розробки; головна — main
Злиття (merge)Об'єднання змін з гілки в main
Pull requestПропозиція змін, яку переглядає команда
Клонування (clone)Копія репозиторію з GitHub на свій комп'ютер
АналогіяІсторія версій у Google Документах — це маленька «система контролю версій». Git робить те саме для цілих папок з кодом і для команд з сотень людей.
