Проєкт «Книжковий рай»: стилі, тестування, публікація

Оживляємо лендинг стилями: кольори, шрифти, Flexbox для секцій і карток. Потім тестуємо в різних браузерах і на смартфоні та публікуємо на GitHub Pages.

План стилізації

БлокГоловне
bodyБез зовнішніх відступів, шрифт Roboto, колір тексту #333

Адаптивністьflex-wrap: wrap і max-width: 100% дозволяють блокам переноситися на вузьких екранах — сайт не «вилазить» за край смартфона.

Тестування

  1. Відкрийте сайт у 2–3 браузерах (Chrome, Edge, Firefox, Opera) — чи однаково виглядає?
  2. DevTools F12 → режим пристрою Ctrl+Shift+M → iPhone, Galaxy: чи не з'являється горизонтальна прокрутка?
  3. Чи всі зображення завантажились, чи немає «биті» значків?
  4. Чи кнопка змінює колір при наведенні, курсор — «рука»?
  5. Валідатор W3C: 0 помилок.

Стилізація і публікація «Книжкового раю»

Мета: оформити лендинг стилями CSS, протестувати його і опублікувати на GitHub Pages.

Заготовки до роботи

⬇ Каркас «Книжкового раю»book-heaven-start.zipЯкщо минулого уроку не встигли, почніть із цього каркаса.
  1. Загальні стилі і головна секція

    Заповніть style.css. Почніть з body і .section-main (код нижче), збережіть, оновіть браузер — і так після кожного блоку.

  2. Решта секцій

    Повний зразок стилів — можна взяти за основу і змінити кольори, розміри, відступи під свій смак:

    margin: 0;
    font-family: 'Roboto', sans-serif;
    color: #333;
    background: #fff;
}
/* ---- головна секція ---- */
.section-main {

    text-align: center;

  3. Протестуйте

    Пройдіть 5 пунктів тестування з теорії. Виправте все, що знайшли.

  4. Опублікуйте

    Як на ПР №15: новий репозиторій book-heaven → Add file → Upload files (index.html, style.css, папка img) → Commit → Settings → Pages → main → Save.

  5. Звіт тестування

    У Google Документі: у яких браузерах і пристроях перевірили, які помилки знайшли і як виправили (2–4 пункти), скріншот сайту на «смартфоні» з DevTools.

Здача роботи
  1. Посилання

    Адреса сайту …github.io/book-heaven/ і репозиторію + звіт тестування.

  2. Здайте в Classroom

    Завдання «Проєкт Книжковий рай» → Здати.

Якщо щось не виходить
Секції злиплися, немає відступів

Перевірте padding у кожної секції і що назви класів у CSS точно збігаються з HTML (без крапки в HTML, з крапкою в CSS).

На смартфоні з'являється горизонтальна прокрутка

Якийсь елемент ширший за екран: додайте йому max-width: 100%, а контейнеру — flex-wrap: wrap.
