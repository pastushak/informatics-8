Змінні і типи даних

Змінна — іменована область пам'яті, у якій зберігається значення. Значення змінній дають за допомогою знака = (присвоєння).

name = "Олександр"     # str — рядок (текст)
age = 14               # int — ціле число
height = 1.69          # float — дійсне (дробове) число
loves_coding = True    # bool — логічне: True або False
print(type(height))
<class 'float'>
ТипНазваПриклади
intЦіле число14, -3, 0
floatДійсне число (крапка, не кома!)1.69, 3.0
strРядок (текст у лапках)"Привіт", '8-А', "14"
boolЛогічне значенняTrue, False

Правила імен змінних

  1. Латинські літери, цифри і _; не починати з цифри: price2 ✔, 2price ✘.
  2. Без пробілів: total_sum.
  3. Регістр важливий: Age і age — різні змінні.
  4. Не можна використовувати слова Python: print, if, for…
  5. Змістовні назви: width, а не x1.

Перше вікно: бібліотека Tkinter

Tkinter — вбудована бібліотека Python для створення програм з вікнами, кнопками і полями. Її не треба встановлювати окремо.

from tkinter import *

window = Tk()                       # створюємо вікно
window.title("Базове вікно")        # заголовок
window.geometry("400x300")          # розмір ШиринаxВисота
window.configure(bg="lightblue")    # колір фону
window.resizable(False, False)      # заборонити зміну розміру

window.mainloop()                   # показати вікно і чекати дій
МетодЩо робить
geometry("450x350+200+100")Розмір і зміщення від лівого і верхнього краю екрана
minsize(300, 300) / maxsize(800, 800)Мінімальний / максимальний розмір
configure(bg="#40E0D0")Колір фону: назва англійською або HEX-код
iconphoto(False, PhotoImage(file="icon.png"))Іконка вікна з PNG-файлу
Важливоmainloop() — завжди останній рядок. Без нього вікно з'явиться і одразу зникне.
