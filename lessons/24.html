Практична робота №15 «Створення сайту на GitHub»

Публікуємо свій сайт в інтернеті: створюємо репозиторій на GitHub, завантажуємо файли через браузер і вмикаємо GitHub Pages. Після уроку ваш сайт матиме справжню адресу.

Як працює GitHub Pages

GitHub Pages бере файли з вашого репозиторію і показує їх як сайт за адресою https://логін.github.io/назва-репозиторію/.

  1. Головна сторінка має називатися index.html і лежати в корені репозиторію (не в підпапці).
  2. Назви файлів і папок — латиницею, без пробілів: my-books, images/cover1.jpg.
  3. Великі й малі літери розрізняються: Photo.JPG ≠ photo.jpg.
  4. Шляхи — відносні: images/cat.jpg, а не C:\Users\….
  5. Після змін сайт оновлюється за 1–2 хвилини.

Робимо · Практична робота №15

Створення сайту на GitHub

Мета: опублікувати власний сайт в інтернеті за допомогою GitHub Pages через вебінтерфейс.

Заготовки до роботи

⬇ Міні-сайт (якщо немає свого)pr15-mini-site.zipГотовий простий сайт для публікації, якщо ваші попередні роботи не збереглися. Допишіть текст про себе.
  1. Увійдіть на github.com

    У свій обліковий запис (створений удома). Немає — Sign up.

  2. Створіть репозиторій

    Кнопка + → New repository:

    • Repository name — латиницею, наприклад my-books;
    • Description — «Мій перший сайт» (необов'язково);
    • Public;
    • позначте Add a README file.

    Натисніть Create repository.

  3. Завантажте файли

    Add file → Upload files. Перетягніть вміст папки сайту (index.html, style.css, папку images), а не саму папку-обгортку.

  4. Зробіть коміт

    У полі Commit changes напишіть «Завантаження сайту» → Commit changes.

  5. Увімкніть GitHub Pages

    Settings → Pages (ліве меню). У розділі Build and deployment → Branch оберіть main, папку / (root) → Save.

  6. Відкрийте свій сайт

    Через 1–2 хвилини оновіть сторінку Settings → Pages: угорі з'явиться Your site is live at… з адресою. Відкрийте її і на смартфоні.

  7. Внесіть зміну

    Відкрийте index.html у репозиторії → олівець Edit → змініть текст → Commit changes. Перевірте, що сайт оновився. Подивіться історію комітів (значок годинника Commits).

Здача роботи
  1. Скопіюйте два посилання

    Адресу сайту (…github.io/…) і адресу репозиторію (github.com/…).

  2. Здайте в Classroom

    Обидва посилання → Здати.

Сайт показує 404

Зачекайте 2–3 хвилини. Перевірте, що файл називається саме index.html (малими літерами) і лежить у корені, а не в папці.

Сайт показує лише README

Немає index.html у корені — GitHub показує README. Завантажте index.html.

Немає стилів або картинок

Порівняйте назви в коді й у репозиторії буква в букву; шлях має бути відносним (style.css, images/1.jpg).

Не бачу пункту Pages

Репозиторій має бути Public. Pages — у Settings, ліве меню, розділ Code and automation.
