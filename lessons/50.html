Коментарі

Коментар — пояснення в коді, яке інтерпретатор пропускає. Пишеться після #.

# Програма обчислює індекс маси тіла
weight = float(input("Вага, кг: "))   # у кілограмах
height = float(input("Зріст, м: "))   # у метрах, напр. 1.65

"""
Багаторядковий рядок у потрійних лапках
часто використовують як довгий опис.
"""
  1. Пояснюйте навіщо, а не що (не «додаємо 1», а «переходимо до наступного учня»).
  2. Коментар на початку файлу: що робить програма, автор, дата.
  3. Тимчасово «вимкнути» рядок: поставити # на початку (Ctrl+/ у VS Code, Alt+3 в IDLE).

Типи помилок

ТипКоли виявляєтьсяПриклад
Синтаксична (SyntaxError, IndentationError)Перед запуском: код написано з порушенням правил мовиprint("Привіт" — бракує дужки; if x > 5 без двокрапки
Помилка виконання (виняток)Під час роботи програмиZeroDivisionError — ділення на 0; ValueError — int("abc"); NameError — змінну не створено
ЛогічнаПрограма працює, але результат неправильнийПлоща a + b замість a * b; range(1, n) замість range(1, n + 1)

Читайте повідомлення Python знизу вгору: остання строчка — тип помилки, вище — номер рядка (line 7). Логічні помилки шукають тестуванням: підставляють дані, для яких відповідь відома.

Обробка помилок і повідомлення

try:
    n = int(input("Число: "))
    print(100 / n)
except ValueError:
    print("Це не число!")
except ZeroDivisionError:
    print("На нуль ділити не можна")
from tkinter import messagebox

messagebox.showinfo("Інформація", "Це інформаційне повідомлення!")
messagebox.showwarning("Попередження", "Будьте уважні!")
messagebox.showerror("Помилка", "Введіть число!")
answer = messagebox.askyesno("Підтвердження", "Ви впевнені?")   # True / False
РазомУ функції кнопки: try — читаємо поля й рахуємо; except ValueError: messagebox.showerror(...) — програма не «падає», а пояснює користувачу, що не так.
