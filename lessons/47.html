Зразок: кислотність з кольором

from tkinter import *

def check_ph():
    ph = float(entry.get())
    if ph < 7:
        result.config(text="Кислий")
        window.configure(bg="tomato")
    elif ph == 7:
        result.config(text="Нейтральний")
        window.configure(bg="lightgreen")
    else:
        result.config(text="Лужний")
        window.configure(bg="lightblue")

window = Tk()
window.title("Кислотність розчину")
window.geometry("300x170")
Label(window, text="Значення pH:").pack(pady=5)
entry = Entry(window); entry.pack()
Button(window, text="Перевірити", command=check_ph).pack(pady=5)
result = Label(window, text=""); result.pack()
window.mainloop()

Складання програм з розгалуженнями

Мета: складати програми з розгалуженнями if / elif / else з графічним інтерфейсом.

Заготовки до роботи

⬇ Файли ПР №24pr24.zipАрхів з .py-файлами. Розпакуйте і відкрийте в IDLE / Thonny / VS Code. Місця, де треба дописати код, позначені # TODO.
  1. Завдання 1. Кислотність

    За зразком: поле pH, кнопка, мітка з результатом «Кислий / Нейтральний / Лужний» і зміна кольору вікна.

  2. Завдання 2. Розрахунок покупки

    Поля: назва товару, ціна, сума грошей у покупця. Кнопка «Розрахувати» викликає calculate():

    • грошей достатньо: «Ви купили Хліб. Ваша решта: 77.0 грн.»
    • недостатньо: «Не вистачає 12.5 грн.»
  3. Завдання 3. Пора року

    Вікно «Визначення пори року»: поле для номера місяця (1–12), кнопка, мітка. Для чисел поза 1–12 — повідомлення про помилку. додатково Свій колір фону для кожної пори року.

  4. Завдання 4. Оцінка додатково

    Бал 1–12 → рівень навчальних досягнень (початковий, середній, достатній, високий).
