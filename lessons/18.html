A1
Читаємо

Що таке HTML

HTML (HyperText Markup Language) — мова гіпертекстової розмітки, якою описують структуру вебсторінки: де заголовок, де абзац, де зображення, де посилання.

HTML — не мова програмування: вона не обчислює, а розмічає вміст. Браузер читає розмітку і показує сторінку. Зовнішній вигляд задає CSS (наступні уроки), поведінку — JavaScript.

Редактори кодуVisual Studio Code (рекомендуємо), Notepad++, навіть Блокнот. Онлайн без встановлення: codepen.io, jsfiddle.net, replit.com.
Файл сторінкиЗвичайний текстовий файл з розширенням .html. Головна сторінка сайту зазвичай називається index.html.
A2
Читаємо

Теги та атрибути. Структура документа

Тег — команда розмітки в кутових дужках. Більшість тегів парні: <p> відкриває, </p> закриває. Одиничні теги не закриваються: <img>, <br>, <hr>.

Атрибут — додаткова властивість тегу, записується у відкривальному тезі: ім'я="значення". Наприклад, <img src="cat.jpg" alt="Кіт">.

<!DOCTYPE html>
<html lang="uk">
<head>
    <meta charset="UTF-8">
    <title>Мої улюблені книги</title>
</head>
<body>
    <h1>Мої улюблені книги</h1>
    <p>Читання відкриває <b>нові світи</b>.</p>
</body>
</html>
ЧастинаПризначення
<!DOCTYPE html>Повідомляє браузеру: це документ HTML5
<html lang="uk">Кореневий елемент, мова сторінки — українська
<head>Службова інформація: кодування, назва вкладки, підключення стилів
<meta charset="UTF-8">Кодування — щоб українські літери не перетворились на «кракозябри»
<title>Текст на вкладці браузера
<body>Усе, що бачить відвідувач
ВкладеністьТеги закриваються у зворотному порядку: <p><b>текст</b></p>, а не <p><b>текст</p></b>.

Валідація сторінок

Валідація — перевірка HTML-коду на відповідність стандартам: незакриті теги, помилки у вкладеності, відсутні обов'язкові атрибути.

  1. Відкрийте validator.w3.orgофіційний валідатор консорціуму W3C
  2. Вкладка «Validate by Direct Input»вставте код або завантажте файл (Validate by File Upload)
  3. Натисніть CheckError — помилка, Warning — попередження
  4. Виправте й перевірте зновудоки не з'явиться «No errors or warnings to show»

Браузери «прощають» помилки, але різні браузери виправляють їх по-різному — і сторінка може «розлізтися». Валідний код однаково працює всюди.

B1
Робимо · Практична робота №12

Створення HTML-документа «Мої улюблені книги»

Мета: створити вебсторінку про улюблені книги з заголовками, абзацами, списками, зображеннями і таблицею та перевірити її валідатором.

  1. Підготуйте папку і файл

    Створіть папку books, у ній — файл index.html (у VS Code: File → New File → зберегти як index.html). Для зображень — підпапка images. Без комп'ютера: codepen.io або replit.com.

  2. Структура документа

    Наберіть каркас: <!DOCTYPE html>, <html lang="uk">, <head> з <meta charset="UTF-8"> і <title>Мої улюблені книги</title>, <body>. У VS Code можна набрати ! і натиснути Tab.

  3. Заголовки й текст

    <h1> «Мої улюблені книги» і розділи <h2>: «Чому я люблю читати», «Мої улюблені книги», «Жанри, які я люблю», «Інформація про книги», «Де купити ці книги». Під першим — абзац 3–4 речення своїми словами.

  4. Списки

    Після «Мої улюблені книги» — нумерований список (3–5 книг: назва — автор). Після «Жанри» — маркований список жанрів.

  5. Зображення

    2–3 обкладинки: частину збережіть у images (src="images/book1.jpg"), одну вставте за інтернет-адресою. Обов'язково alt, ширина 200.

  6. Таблиця

    Таблиця з рядком-заголовком <th>: Назва · Автор · Жанр · Рік. Атрибути border="1" cellpadding="10" cellspacing="0".

  7. Оформлення тексту
    • Виділіть курсивом «Читання книг» (<i>), напівжирним — «нові світи» (<b>), підсвітіть одне слово (<mark>).
    • Розділіть розділи горизонтальною лінією <hr>.
  8. Валідація

    Перевірте файл на validator.w3.org і виправте всі помилки. Зробіть скріншот результату.

Здача роботи
  1. Заархівуйте папку

    ZIP-архів папки books з index.html і зображеннями (або посилання на codepen/replit).

  2. Здайте в Classroom

    Архів + скріншот валідатора → Здати.
