Зразок: генерація і перевірка

from tkinter import *
import random

num1 = num2 = 0

def generation():
    global num1, num2
    num1 = random.randint(1, 10)
    num2 = random.randint(1, 10)
    first.config(text=f"Перше число: {num1}")
    second.config(text=f"Друге число: {num2}")

def check():
    result.config(text=f"Результат: {num1 == num2}")

window = Tk()
window.title("Перевірка рівності")
window.geometry("300x200")
first = Label(window, text="Перше число: ?"); first.pack()
second = Label(window, text="Друге число: ?"); second.pack()
Button(window, text="Згенерувати", command=generation).pack(pady=3)
Button(window, text="Перевірити", command=check).pack(pady=3)
result = Label(window, text="Результат:"); result.pack()
window.mainloop()

Робимо · Практична робота №23

Складання програмних проєктів з використанням логічних операторів

Мета: складати програми з логічними виразами, що виводять True або False.

  1. Завдання 1. Рівність випадкових чисел

    За зразком: кнопка «Згенерувати» створює два числа від 1 до 10, кнопка «Перевірити» показує, чи рівні вони.

  2. Завдання 2. Чи перше більше?

    Два поля для чисел, кнопка «Перевірити» викликає check1():

    num1 = float(entry1.get())
num2 = float(entry2.get())
res = num1 > num2

    Мітка: «Чи перше число більше? True/False».

  3. Завдання 3. Перевірка на парність

    Поле для цілого числа, кнопка, мітка з результатом n % 2 == 0.

  4. Завдання 4. Двоцифрове число

    Перевірте, чи введене число двоцифрове: 10 <= abs(n) <= 99.

  5. Завдання 5. Високосний рік додатково

    Введіть рік і виведіть, чи високосний він (умова — у самоперевірці).
