Читаємо

Нагадування: введення чисел

Функція input() завжди повертає рядок. Щоб рахувати, перетворіть його на число: int() — ціле, float() — дробове.

a = float(input("Введіть довжину саду: "))
b = float(input("Введіть ширину саду: "))
print("Площа:", a * b, "м²")
Типова помилкаБез перетворення input("…") + input("…") з 2 і 3 дасть 23 — рядки склеюються, а не додаються.
Немає комп'ютера з Python?Консольні програми (з print та input) можна запускати онлайн: onlinegdb.com (оберіть Language: Python 3), programiz.com/python-programming/online-compiler, на смартфоні — застосунок Pydroid 3. Програми з вікнами Tkinter онлайн не працюють — у Pydroid 3 вони запускаються.

Створення змінних та робота з типами даних

Мета: створювати змінні різних типів, обчислювати за формулами введені дані і налаштовувати вікна Tkinter.

Заготовки до роботи

⬇ Файли ПР №20pr20.zipАрхів з .py-файлами. Розпакуйте і відкрийте в IDLE / Thonny / VS Code. Місця, де треба дописати код, позначені # TODO.
  1. Завдання 1. Про себе

    Створіть 4 змінні: ім'я (str), вік (int), зріст у метрах (float), чи любите програмування (bool). Виведіть:

    print("Моє ім'я:", name)
print("Мені", age, "років")
print("Мій зріст:", height, "м")
print("Чи люблю програмувати:", loves_programming)
  2. Завдання 2. Сад

    Користувач вводить довжину і ширину саду. Обчисліть периметр (довжина паркану) і площу (скільки засіяти). додатково Скільки грамів насіння купити, якщо на 1 м² — 300 г?

  3. Завдання 3. Гаманець

    Запитайте, скільки монет по 1, 2, 5 і 10 гривень і купюр по 20, 50, 100 грн. Обчисліть і виведіть загальну суму.

  4. Завдання 4. Вікна з різними властивостями (Tkinter)
    • а) 400×300, заголовок «Базове вікно», фон "blue", без зміни розміру.
    • б) 500×500, «Обмеження розміру», фон у форматі HEX, мінімум 300×300, максимум 800×800.
    • в) 450×350, «Вікно зі зміщенням», фон бірюзовий "turquoise", зміщення 200 і 100 пікселів: geometry("450x350+200+100").
  5. Завдання 5. Вікно з іконкою додатково

    Вікно 300×200, заголовок «Вікно з іконкою». Збережіть невелике PNG-зображення в папку з програмою:

    icon = PhotoImage(file="myicon.png")
window.iconphoto(False, icon)

Якщо щось не виходить
ValueError: could not convert string to float

Ви ввели число з комою (2,5). У Python — крапка: 2.5.

TclError: unknown color name

Назва кольору англійською без помилок ("turquoise") або HEX з решіткою ("#40E0D0").
